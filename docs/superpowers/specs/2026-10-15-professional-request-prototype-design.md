# Prototipo de solicitud directa de profesionales

## Objetivo

Crear un prototipo HTML aislado que permita validar un segundo embudo de captación para personas que buscan directamente un profesional, sin obligarlas a generar antes un presupuesto y sin modificar producción.

## Recorrido del cliente

Cada tarjeta representa una especialidad, nunca una empresa ficticia. Las fotografías son distintas entre especialidades y distintas de las imágenes superiores del landing. Al pulsar «Solicitar profesional» se abre un asistente sobre la misma página con cinco etapas: servicio, ubicación, proyecto, contacto y revisión. La dirección exacta permanece privada y solo se usa para calcular la zona de servicio.

La confirmación genera una referencia, explica que robotARQ revisará la solicitud y muestra el estado del expediente. El prototipo simula el proceso; no envía datos, correos ni cobros reales.

## Monetización inicial

La solicitud y la revisión inicial son gratuitas. Si robotARQ confirma candidatos compatibles, el cliente puede activar una búsqueda gestionada por 14,90 euros. Incluye selección y presentación de hasta tres candidatos; no se cobra si no se encuentra ninguno en siete días laborables. El importe se descuenta de una posterior revisión técnica o gestión de obra.

Este modelo permite monetizar antes de contar con una red amplia y evita cobrar por una búsqueda sin resultado. Cuando crezca la red propia podrá convivir con créditos pagados por profesionales para acceder a oportunidades verificadas.

## Administración

La demostración incluye dos bandejas separadas: «Presupuestos y ofertas» y «Solicitudes de profesionales». La segunda muestra servicio, zona, urgencia, cliente, estado y puntuación de calidad. La ficha de solicitud contiene los datos, la dirección privada, los criterios de búsqueda y un botón para simular la búsqueda.

Los candidatos se ordenan por especialidad, distancia, verificación, disponibilidad y adecuación. El administrador selecciona hasta tres y prepara correos personalizados. Nada se envía automáticamente desde el prototipo.

## Requisitos visuales

- Arquitectura visual robotARQ, plenamente responsive.
- Imágenes naturales de trabajos reales en contexto español y luz neutra.
- Fotografías diferentes para reforma integral, albañilería/alicatado, fontanería, electricidad y arquitectura técnica.
- Sin nombres de empresas ficticias presentados como negocios reales.
- Flujo navegable desde tarjetas hasta confirmación y administración.
- Indicador visible de que se trata de una demostración sin efectos reales.

## Límites

El prototipo no se publica en robotarq.com, no crea usuarios, no guarda datos, no cobra y no envía correos. La integración real de almacenamiento, correo, búsqueda externa, pagos y privacidad será una fase posterior tras aprobar el recorrido.
